# nagi-pokke-media

Public, immutable hosting for images that were approved for posts on @nagiandpokke.

- Files are named by the SHA-256 of their exact bytes and are never overwritten.
- Only approved images whose rights allow public hosting are added, by an automated job.
- Drafts, rights evidence, ledgers and other private records are never stored here.
- Takedown requests: open an issue in this repository. An image still referenced by a
  queued post is removed only after that post is cancelled.

Nagi & Pokke is a fan community. It is not affiliated with or endorsed by the goats'
caretakers or by JR East.
